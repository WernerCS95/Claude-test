# Install — one app on both devices (20 Oct 2026)

**Never uninstall anything.** If Android says "App not installed", "conflicts with an
existing package" or asks you to uninstall first: STOP and send a screenshot.

## A. Build both (laptop, Command Prompt)

1. Open Command Prompt (Windows key → type `cmd` → Enter) and run:
   ```
   cd /d "C:\Users\werne\OneDrive\Desktop\Claude-test"
   git pull origin claude/blissful-mccarthy-k7if0c
   ```
2. Build the EXE:
   ```
   cd desktop-app
   npm install
   npm run dist
   dir dist\*.exe
   ```
   You need **`Leader Master List Setup 2.0.0.exe`** with today's date and time. If it isn't there, stop.
3. Build the APK:
   ```
   cd ..\android-app
   npm install
   npx cap sync android
   npx cap open android
   ```
   Android Studio → **Build → Build App Bundle(s)/APK(s) → Build APK(s)** → wait for **BUILD SUCCESSFUL**.
4. Check it's fresh, back in Command Prompt:
   ```
   dir android\app\build\outputs\apk\debug\app-debug.apk
   ```
   The time must be from just now. Upload it to Google Drive as **`leader-stores-2.0.apk`**.

## B. Laptop

1. **Back up (old apps):** Master List → **💾 Save Today's List**. A `leader-master-backup-….json` file appears in Downloads.
   If the laptop also has the Terminal app: open it → **⚙ More → 💾 Download Backup Now**. Keep that file too.
2. Close every Leader app. Run **`Leader Master List Setup 2.0.0.exe`** (in `desktop-app\dist`) and install over the top.
3. Open **Leader Master List**. The top bar now shows **LEADER STORES** with **📥 Input | 🛠 Admin**, and it opens on Admin.
4. Admin → **🔎 Verify Against Backup** → pick the file from step 1. Every section should match. Send me a screenshot.

The laptop's Input section starts empty. That's expected; the laptop is the admin device.

## C. Tablet

1. **Back up (old apps):**
   - **Leader Stores Terminal → ⚙ More → 💾 Download Backup Now**, then **📤 Export & Share Full Current State** → share it to Drive.
   - **Leader Master List → 💾 Backup & Share** → share it to Drive. **This file is the data move in step 4.**
2. **Install:** open `leader-stores-2.0.apk` from Drive → **Update**. It goes over Leader Stores Terminal.
3. **Check Input:** open **Leader Stores Terminal**. It opens on **📥 Input**. Then **⚙ More → 🔎 Verify Against Backup**:
   - pick the **Full State** file → every item's qty should match
   - pick the **backup** file → every section should match.
4. **Data move:** tap **🛠 Admin**. A red "NO SAVED DATA" banner is expected at this point.
   Tap **🛟 Restore Backup**, pick the **Master List backup** from step 1, and confirm. Admin reloads with your data.
5. **Check Admin:** **🔎 Verify Against Backup** → same Master List file → every section should match. Send me a screenshot.
6. Leave the old **Leader Master List** app installed but don't use it. It stays as a fallback for a few days, then we remove it.
