# 2pm Install — Stock Count update (7 Oct 2026)

**Rule for the whole install: never uninstall anything.** If any installer says
"App not installed", "conflicts with an existing package" or asks to uninstall
first — STOP and send a screenshot. Uninstalling wipes the tablet's data.

## Before 2pm — build (on the laptop, same PC as the last APK build)

```
cd "$env:OneDrive\Desktop\Claude-test"
git pull origin claude/blissful-mccarthy-k7if0c
```

**EXE (Master List, laptop):**
```
cd desktop-app
npm install
npm run dist
Get-Item "dist\Leader Master List Setup 1.0.0.exe" | Select-Object LastWriteTime
cd ..
```
LastWriteTime must be from the last few minutes, or the build is stale.

**APK (Stores Terminal, tablet):**
```
cd android-app
npm install
npx cap sync android
npx cap open android
```
Android Studio: Build → Build App Bundle(s)/APK(s) → Build APK(s). Wait for
`BUILD SUCCESSFUL`. Then:
```
Get-Item android\app\build\outputs\apk\debug\app-debug.apk | Select-Object LastWriteTime
```
Copy it to Google Drive under a **new name**, e.g. `terminal-2026-10-07.apk`.

## 1. Backups (old apps, before installing anything)

- **Laptop:** 💾 Save Today's List — saves the CSV **and** `leader-master-backup-….json`.
- **Tablet:** ⚙ More → 💾 Download Backup Now, **and** ⚙ More → 📤 Export & Share
  Full Current State. Both are needed: the old tablet backup doesn't contain the
  stock quantities; the Full State file does.
- Copy all backup files off the laptop (USB or Drive). Leave the tablet files in Documents too.

## 2. Install the EXE over the top → verify

- Close Master List. Run the new installer. Don't uninstall first.
- Open it → 🔎 Verify Against Backup → pick the laptop backup from step 1.
- Expect: every section matches, every count the same before → after. Screenshot it.

## 3. Install the APK over the top (NO uninstall) → verify

- On the tablet, download `terminal-2026-10-07.apk` from Drive, tap it, Update.
- ⚙ More → 🔎 Verify Against Backup → pick the **Full State** file → every item's
  qty should match. Then run it again with the **backup** file → every section matches.
  Screenshot both.
- ⚙ More → 💾 Download Backup Now once more — the new backup now includes stock quantities.

## 4. Counts → laptop → tablet

- Laptop: 📝 Stock Count. Fill in **Counted by**, and set **Count taken at** to when
  the physical count was actually done (not now).
- Pick a group, type each qty, press Enter (saves and jumps to the next item).
  If anything moved on the laptop after the count time, it asks before saving.
- 📤 Export Pending Counts → send the file to the tablet (Drive/WhatsApp/USB).
- Tablet: 🖨 Full Count → 📥 Import Counts → pick the file → check the preview:
  Counted, Tablet activity after count, Will be set to, Difference → Apply.

## 5. Final check + print

- Spot-check a handful of items: laptop On Hand = tablet Qty on Hand.
- Laptop: 📊 Stock Level Report → Below min only (or All) → untick groups not
  wanted → 🖨 Print.
